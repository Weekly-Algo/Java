# 백준 2164번 — 카드2 풀이

## 1. 문제 이해하기

`1번`부터 `N번`까지 번호가 붙은 카드가 한 줄로 쌓여 있다.

카드는 위에서부터 다음과 같은 순서로 놓여 있다.

```text
1, 2, 3, ..., N
```

카드가 한 장 남을 때까지 아래의 두 동작을 반복한다.

1. 가장 위에 있는 카드를 버린다.
2. 그다음 가장 위에 있는 카드를 맨 아래로 옮긴다.

마지막에 남는 카드의 번호를 출력하는 문제이다.

### 입력과 출력

- 입력: 카드의 개수 `N`
- 출력: 마지막에 남는 카드 번호

예를 들어 `N = 6`이라면 마지막에 `4번` 카드가 남으므로 `4`를 출력한다.

---

## 2. 어떤 자료구조를 사용해야 할까?

이 문제에서는 다음 두 가지 동작이 계속 필요하다.

- 맨 앞의 카드를 제거한다.
- 맨 앞의 카드를 꺼내 맨 뒤에 넣는다.

이 동작은 **큐(Queue)**의 동작과 정확히 일치한다.

큐는 먼저 들어온 값이 먼저 나가는 **선입선출(FIFO)** 자료구조이다.

```text
큐의 앞                                      큐의 뒤
카드를 꺼내는 곳  [1, 2, 3, 4, 5, 6]  카드를 넣는 곳
```

Java의 큐에서는 다음 메서드를 사용한다.

| 메서드 | 의미 |
|---|---|
| `offer(value)` | 값을 큐의 맨 뒤에 넣는다. |
| `poll()` | 큐의 맨 앞 값을 꺼내면서 제거한다. |
| `peek()` | 큐의 맨 앞 값을 제거하지 않고 확인한다. |
| `size()` | 큐에 들어 있는 값의 개수를 구한다. |

---

## 3. 핵심 아이디어

먼저 `1`부터 `N`까지의 카드 번호를 큐에 차례대로 넣는다.

그다음 큐에 카드가 한 장만 남을 때까지 다음 동작을 반복한다.

```text
1. poll()로 맨 앞 카드를 제거하여 버린다.
2. poll()로 그다음 카드를 꺼낸다.
3. offer()로 꺼낸 카드를 맨 뒤에 다시 넣는다.
```

카드가 한 장만 남으면 `peek()`으로 그 카드 번호를 확인하여 출력한다.

---

## 4. 예제로 동작 이해하기

`N = 6`인 경우 처음 큐의 상태는 다음과 같다.

```text
앞 [1, 2, 3, 4, 5, 6] 뒤
```

| 반복 | 실행한 동작 | 큐의 상태 |
|---:|---|---|
| 처음 | `1`부터 `6`까지 저장 | `[1, 2, 3, 4, 5, 6]` |
| 1 | `1`을 버림 | `[2, 3, 4, 5, 6]` |
| 1 | `2`를 맨 뒤로 옮김 | `[3, 4, 5, 6, 2]` |
| 2 | `3`을 버림 | `[4, 5, 6, 2]` |
| 2 | `4`를 맨 뒤로 옮김 | `[5, 6, 2, 4]` |
| 3 | `5`를 버림 | `[6, 2, 4]` |
| 3 | `6`을 맨 뒤로 옮김 | `[2, 4, 6]` |
| 4 | `2`를 버림 | `[4, 6]` |
| 4 | `4`를 맨 뒤로 옮김 | `[6, 4]` |
| 5 | `6`을 버림 | `[4]` |

마지막에 `4`만 남으므로 정답은 `4`이다.

### 한 번의 반복을 자세히 보기

큐가 다음 상태라고 가정하자.

```text
[1, 2, 3, 4, 5, 6]
```

먼저 맨 앞 카드 `1`을 버린다.

```java
queue.poll();
```

```text
[2, 3, 4, 5, 6]
```

그다음 맨 앞 카드 `2`를 꺼내 맨 뒤에 넣는다.

```java
int card = queue.poll();
queue.offer(card);
```

```text
[3, 4, 5, 6, 2]
```

이것이 문제에서 말한 두 동작을 한 번 수행한 결과이다.

## 5. 전체 알고리즘 순서

1. 입력으로 카드 개수 `N`을 받는다.
2. 큐를 만든다.
3. `1`부터 `N`까지의 카드 번호를 큐에 넣는다.
4. 큐의 크기가 `1`보다 큰 동안 다음을 반복한다.
   1. 맨 앞 카드를 꺼내 버린다.
   2. 그다음 맨 앞 카드를 꺼낸다.
   3. 꺼낸 카드를 큐의 맨 뒤에 넣는다.
5. 큐에 마지막으로 남은 카드 번호를 출력한다.

---

## 6. Java 정답 코드

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.ArrayDeque;
import java.util.Queue;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br =
                new BufferedReader(new InputStreamReader(System.in));

        int N = Integer.parseInt(br.readLine());

        Queue<Integer> queue = new ArrayDeque<>();

        // 1번부터 N번까지 카드를 순서대로 넣는다.
        for (int i = 1; i <= N; i++) {
            queue.offer(i);
        }

        // 카드가 한 장 남을 때까지 반복한다.
        while (queue.size() > 1) {
            // 가장 위의 카드를 버린다.
            queue.poll();

            // 그다음 가장 위의 카드를 맨 아래로 옮긴다.
            int card = queue.poll();
            queue.offer(card);
        }

        // 마지막으로 남은 카드를 출력한다.
        System.out.println(queue.peek());
    }
}
```

## 7. 코드 구간별 해석

### 입력 받기

```java
BufferedReader br =
        new BufferedReader(new InputStreamReader(System.in));

int N = Integer.parseInt(br.readLine());
```

`BufferedReader`로 한 줄을 읽으면 문자열이 반환된다.

`Integer.parseInt()`를 사용하여 읽은 문자열을 정수로 변환하고 `N`에 저장한다.

---

### 큐 만들기

```java
Queue<Integer> queue = new ArrayDeque<>();
```

정수형 카드 번호를 저장할 큐를 만든다.

- `Queue<Integer>`: 큐 방식으로 사용하겠다는 의미
- `ArrayDeque<>()`: 실제로 데이터를 저장하고 큐 동작을 처리하는 자료구조

`LinkedList`로도 풀 수 있지만, 앞뒤에서 데이터를 넣고 빼는 단순한 큐에는 일반적으로 `ArrayDeque`가 적합하다.

---

### 카드 번호 저장하기

```java
for (int i = 1; i <= N; i++) {
    queue.offer(i);
}
```

문제에서 카드는 위에서부터 `1, 2, 3, ..., N` 순서로 놓여 있다.

따라서 반복문을 이용해 `1`부터 `N`까지 차례대로 큐에 넣는다.

`N = 6`이면 다음 상태가 된다.

```text
[1, 2, 3, 4, 5, 6]
```

---

### 카드가 한 장 남을 때까지 반복하기

```java
while (queue.size() > 1) {
```

문제의 동작은 카드가 한 장 남을 때까지 반복해야 한다.

따라서 큐에 카드가 두 장 이상 들어 있을 때만 반복한다.

조건을 `queue.size() >= 1`로 작성하면 카드가 한 장일 때도 `poll()`을 실행하여 마지막 카드까지 제거할 수 있으므로 주의해야 한다.

---

### 맨 위 카드 버리기

```java
queue.poll();
```

`poll()`은 큐의 맨 앞 카드를 꺼내면서 제거한다.

이 카드는 버릴 카드이므로 번호를 변수에 저장할 필요가 없다.

---

### 다음 카드를 맨 아래로 옮기기

```java
int card = queue.poll();
queue.offer(card);
```

`poll()`로 현재 맨 앞 카드를 꺼내고, `offer()`로 그 카드를 큐의 맨 뒤에 넣는다.

두 줄을 다음과 같이 한 줄로 작성할 수도 있다.

```java
queue.offer(queue.poll());
```

하지만 큐를 처음 공부하는 단계에서는 변수를 사용한 코드가 동작을 구분하기 쉽다.

---

### 마지막 카드 출력하기

```java
System.out.println(queue.peek());
```

반복문이 끝났다는 것은 큐에 카드가 한 장만 남았다는 의미이다.

`peek()`으로 맨 앞의 카드 번호를 확인하여 출력한다. `peek()`은 값을 제거하지 않는다.

이 문제에서는 한 장만 남아 있기 때문에 `poll()`로 출력해도 정답에는 문제가 없지만, 단순 확인이라는 의미에는 `peek()`이 더 잘 맞는다.

---

## 8. 왜 배열보다 큐가 적합할까?

배열로도 카드의 현재 위치를 직접 관리할 수 있지만, 맨 앞 값을 제거하고 나머지 값을 계속 앞으로 옮긴다면 한 번의 제거에 많은 연산이 필요할 수 있다.

큐를 사용하면 다음 동작을 효율적으로 처리할 수 있다.

- 맨 앞 값 제거: `poll()`
- 맨 뒤에 값 추가: `offer()`

두 연산 모두 `ArrayDeque`에서 평균적으로 \(O(1)\)에 처리된다.

---

## 9. 시간 복잡도와 공간 복잡도

### 시간 복잡도

각 반복에서 카드를 한 장 버리므로 반복 횟수는 `N - 1`번이다.

한 번 반복할 때 실행하는 `poll()`과 `offer()`는 각각 \(O(1)\)이다.

따라서 전체 시간 복잡도는 다음과 같다.

\[
O(N)
\]

### 공간 복잡도

처음에 `N`장의 카드를 모두 큐에 저장한다.

따라서 공간 복잡도는 다음과 같다.

\[
O(N)
\]

## 10. 자주 하는 실수

### 1) 카드 이동 순서를 반대로 처리하는 경우

문제의 순서는 반드시 다음과 같다.

1. 첫 번째 카드를 버린다.
2. 그다음 카드를 맨 뒤로 옮긴다.

처음부터 카드를 뒤로 옮기거나 두 장을 모두 버리면 다른 결과가 나온다.

### 2) 반복 조건을 잘못 작성하는 경우

```java
while (queue.size() > 1)
```

카드가 한 장만 남으면 반복을 멈춰야 한다.

### 3) 이동할 카드를 다시 넣지 않는 경우

```java
int card = queue.poll();
queue.offer(card);
```

두 번째 카드는 버리는 것이 아니라 맨 뒤로 옮겨야 하므로 반드시 다시 큐에 넣어야 한다.

### 4) `poll()`과 `peek()`을 혼동하는 경우

- `poll()`: 값을 확인하고 큐에서 제거한다.
- `peek()`: 값만 확인하고 제거하지 않는다.

카드를 버리거나 옮길 때는 `poll()`, 마지막 정답을 확인할 때는 `peek()`을 사용한다.

---

## 11. 핵심 정리

이 문제의 핵심은 카드 더미를 큐로 표현하는 것이다.

> 카드의 맨 위는 큐의 앞, 카드의 맨 아래는 큐의 뒤라고 생각한다.

핵심 반복 코드는 다음과 같다.

```java
while (queue.size() > 1) {
    queue.poll();              // 맨 위 카드 버리기
    queue.offer(queue.poll()); // 다음 카드를 맨 아래로 옮기기
}
```

한 문장으로 정리하면 다음과 같다.

> 맨 앞 카드를 제거하고 다음 맨 앞 카드를 맨 뒤로 보내는 동작을, 카드가 한 장 남을 때까지 큐로 반복하는 문제이다.
