# 프로그래머스 — 야근 지수

## 1. 문제 한눈에 이해하기

여러 개의 일이 있고, 각 일을 끝내는 데 필요한 시간이 `works` 배열에 들어 있다.

- `works[i]`: i번째 일의 남은 작업량
- `n`: 앞으로 일할 수 있는 시간
- 1시간 동안 할 수 있는 일: 작업 하나를 골라 작업량을 `1` 줄이기

`n`시간이 지난 뒤 남은 작업량을 각각 제곱하여 더한 값을 **야근 지수**라고 한다.

\[
야근\ 지수 = 남은\ 작업량_1^2 + 남은\ 작업량_2^2 + \cdots
\]

우리가 구해야 하는 것은 **가능한 야근 지수 중 최솟값**이다.

### 예시

```text
n = 4
works = [4, 3, 3]
```

4시간 동안 작업량을 총 4만큼 줄일 수 있다.

가장 큰 작업부터 하나씩 줄이면 다음과 같다.

```text
[4, 3, 3]
→ [3, 3, 3]
→ [2, 3, 3]
→ [2, 2, 3]
→ [2, 2, 2]
```

따라서 야근 지수는 다음과 같다.

\[
2^2 + 2^2 + 2^2 = 12
\]

---

## 2. 핵심 아이디어

### 가장 큰 작업량부터 줄인다

야근 지수는 남은 작업량을 **제곱**해서 계산한다. 따라서 작은 수보다 큰 수를 줄였을 때 야근 지수가 더 많이 감소한다.

예를 들어 현재 작업량이 `[4, 2]`이고 1시간만 일할 수 있다고 해보자.

#### 큰 값 4를 줄이는 경우

```text
[4, 2] → [3, 2]
```

\[
3^2 + 2^2 = 9 + 4 = 13
\]

#### 작은 값 2를 줄이는 경우

```text
[4, 2] → [4, 1]
```

\[
4^2 + 1^2 = 16 + 1 = 17
\]

`13 < 17`이므로 큰 작업량부터 줄이는 편이 유리하다.

### 수식으로 확인하기

작업량이 `x`일 때 이를 1 줄이면 제곱값은 다음만큼 감소한다.

\[
x^2 - (x-1)^2
\]

식을 풀면 다음과 같다.

\[
x^2 - (x^2 - 2x + 1) = 2x - 1
\]

`x`가 클수록 `2x - 1`도 커진다. 즉, **현재 가장 큰 작업량을 줄일 때 야근 지수가 가장 많이 감소한다.**

이처럼 매 순간 가장 좋은 선택을 반복하는 방법을 **그리디(Greedy) 알고리즘**이라고 한다.

---

## 3. 가장 큰 값을 어떻게 빠르게 찾을까?

매시간 다음 작업을 반복해야 한다.

1. 현재 작업량 중 가장 큰 값을 찾는다.
2. 그 값을 1 줄인다.
3. 줄어든 값을 다시 작업 목록에 넣는다.

배열을 매번 정렬할 수도 있지만, `n`번 반복하면서 계속 정렬하면 불필요한 연산이 많다.

이 문제에서는 **최대 힙(Max Heap)**을 사용하면 가장 큰 값을 효율적으로 관리할 수 있다.

Java에서는 `PriorityQueue`가 기본적으로 가장 작은 값을 먼저 꺼내는 최소 힙이다. 따라서 `Collections.reverseOrder()`를 전달해 최대 힙으로 만들어야 한다.

```java
PriorityQueue<Integer> maxHeap =
        new PriorityQueue<>(Collections.reverseOrder());
```

최대 힙에서는 다음 연산을 할 수 있다.

- `offer(value)`: 값을 힙에 넣는다.
- `poll()`: 가장 큰 값을 꺼낸다.
- `isEmpty()`: 힙이 비어 있는지 확인한다.

---

## 4. 전체 알고리즘

1. 모든 작업량을 최대 힙에 넣는다.
2. 전체 작업량의 합을 계산한다.
3. 전체 작업량이 `n` 이하라면 모든 일을 끝낼 수 있으므로 `0`을 반환한다.
4. `n`이 0이 될 때까지 다음을 반복한다.
   - 최대 힙에서 가장 큰 작업량을 꺼낸다.
   - 작업량을 1 줄인다.
   - 줄어든 작업량을 다시 최대 힙에 넣는다.
5. 힙에 남은 모든 작업량을 제곱하여 더한다.
6. 계산한 야근 지수를 반환한다.

---

## 5. Java 코드

```java
import java.util.Collections;
import java.util.PriorityQueue;

class Solution {
    public long solution(int n, int[] works) {
        PriorityQueue<Integer> maxHeap =
                new PriorityQueue<>(Collections.reverseOrder());

        long totalWork = 0;

        for (int work : works) {
            maxHeap.offer(work);
            totalWork += work;
        }

        // n시간 안에 모든 일을 끝낼 수 있는 경우
        if (totalWork <= n) {
            return 0;
        }

        // 매시간 가장 큰 작업량을 1씩 줄인다.
        while (n > 0) {
            int maxWork = maxHeap.poll();
            maxHeap.offer(maxWork - 1);
            n--;
        }

        long answer = 0;

        // 남은 작업량의 제곱을 모두 더한다.
        while (!maxHeap.isEmpty()) {
            long work = maxHeap.poll();
            answer += work * work;
        }

        return answer;
    }
}
```

## 6. 코드 구간별 해석

### 6-1. 최대 힙 만들기

```java
PriorityQueue<Integer> maxHeap =
        new PriorityQueue<>(Collections.reverseOrder());
```

- `PriorityQueue<Integer>`: 정수를 우선순위에 따라 관리하는 자료구조
- `Collections.reverseOrder()`: 큰 수가 먼저 나오도록 순서를 반대로 설정
- 결과적으로 `poll()`을 호출하면 가장 큰 작업량을 꺼낼 수 있다.

### 6-2. 작업량을 힙에 넣고 합계 구하기

```java
long totalWork = 0;

for (int work : works) {
    maxHeap.offer(work);
    totalWork += work;
}
```

향상된 `for`문으로 `works`의 값을 하나씩 꺼낸다.

- `maxHeap.offer(work)`: 작업량을 최대 힙에 저장
- `totalWork += work`: 모든 작업량의 합 계산

전체 작업량의 합은 입력 범위가 커질 때를 고려해 `long`으로 선언한다.

### 6-3. 모든 일을 끝낼 수 있는지 확인하기

```java
if (totalWork <= n) {
    return 0;
}
```

예를 들어 작업량이 `[1, 2]`라면 총 작업량은 3이다.

- `n = 3`: 모든 일을 정확히 끝낼 수 있다.
- `n = 5`: 일을 모두 끝내고도 2시간이 남는다.

두 경우 모두 남은 작업량은 전부 0이므로 야근 지수도 0이다.

이 조건을 먼저 검사하면 이후 반복문에서 작업량이 0보다 작아지는 것도 방지할 수 있다.

### 6-4. 가장 큰 작업량 줄이기

```java
while (n > 0) {
    int maxWork = maxHeap.poll();
    maxHeap.offer(maxWork - 1);
    n--;
}
```

한 번 반복할 때 1시간을 사용한다.

1. `poll()`로 가장 큰 작업량을 꺼낸다.
2. `maxWork - 1`로 1시간만큼 처리한다.
3. 남은 작업량을 다시 힙에 넣는다.
4. 사용 가능한 시간 `n`을 1 줄인다.

줄어든 값을 다시 힙에 넣는 이유는 다음 시간에는 다른 작업이 가장 큰 값이 될 수 있기 때문이다.

### 6-5. 야근 지수 계산하기

```java
long answer = 0;

while (!maxHeap.isEmpty()) {
    long work = maxHeap.poll();
    answer += work * work;
}
```

힙에 남아 있는 모든 작업량을 하나씩 꺼내 제곱한 후 `answer`에 더한다.

`answer`와 `work`를 `long`으로 선언한 이유는 제곱 결과가 `int`의 범위를 넘을 수 있기 때문이다.

```java
long work = maxHeap.poll();
answer += work * work;
```

`work`가 `long`이므로 `work * work`도 `long` 연산이 된다.

## 7. 예제로 힙의 변화 추적하기

```text
n = 4
works = [4, 3, 3]
```

최대 힙은 내부 배열이 정렬된 모습과 정확히 같지는 않지만, 이해를 위해 작업량을 큰 순서대로 표시하면 다음과 같다.

| 반복 | 꺼낸 최댓값 | 1을 줄인 값 | 힙의 작업량 | 남은 시간 |
|---:|---:|---:|---|---:|
| 시작 | - | - | `[4, 3, 3]` | 4 |
| 1 | 4 | 3 | `[3, 3, 3]` | 3 |
| 2 | 3 | 2 | `[3, 3, 2]` | 2 |
| 3 | 3 | 2 | `[3, 2, 2]` | 1 |
| 4 | 3 | 2 | `[2, 2, 2]` | 0 |

최종 야근 지수는 다음과 같다.

\[
2^2 + 2^2 + 2^2 = 12
\]

## 8. 시간 복잡도

작업의 개수를 `m`이라고 하자.

### 힙에 처음 작업량을 넣기

작업 `m`개를 힙에 넣으므로 대략 다음 시간이 필요하다.

\[
O(m \log m)
\]

### n시간 동안 작업하기

한 시간마다 `poll()`과 `offer()`를 한 번씩 수행한다. 두 연산 모두 최대 `O(log m)`이므로 다음 시간이 필요하다.

\[
O(n \log m)
\]

### 야근 지수 계산하기

힙에서 작업량 `m`개를 꺼내므로 다음 시간이 필요하다.

\[
O(m \log m)
\]

따라서 전체 시간 복잡도는 다음과 같이 정리할 수 있다.

\[
O((n+m)\log m)
\]

공간 복잡도는 작업량 `m`개를 힙에 저장하므로 다음과 같다.

\[
O(m)
\]

## 9. 자주 하는 실수

### 실수 1. 기본 PriorityQueue를 그대로 사용하기

```java
PriorityQueue<Integer> heap = new PriorityQueue<>();
```

이 코드는 가장 작은 값이 먼저 나오는 **최소 힙**이다. 이 문제에서는 가장 큰 값을 꺼내야 하므로 다음과 같이 작성해야 한다.

```java
PriorityQueue<Integer> maxHeap =
        new PriorityQueue<>(Collections.reverseOrder());
```

### 실수 2. 꺼낸 값을 다시 넣지 않기

```java
int maxWork = maxHeap.poll();
maxWork--;
```

이렇게만 작성하면 줄어든 작업이 힙에서 사라진다. 반드시 다시 넣어야 한다.

```java
maxHeap.offer(maxWork - 1);
```

### 실수 3. 모든 일을 끝낼 수 있는 경우를 처리하지 않기

전체 작업량보다 `n`이 크면 작업량을 음수까지 줄일 수 있다. 먼저 다음 조건을 확인해야 한다.

```java
if (totalWork <= n) {
    return 0;
}
```

### 실수 4. 제곱 계산을 int로 하기

```java
int work = maxHeap.poll();
answer += work * work;
```

`work * work`는 먼저 `int`로 계산된다. 계산 중 오버플로가 발생한 뒤 `long`에 저장될 수 있다.

안전하게 다음과 같이 `work`를 `long`으로 받는다.

```java
long work = maxHeap.poll();
answer += work * work;
```

---

## 10. 이 문제에서 기억할 것

- 제곱의 합을 최소화하려면 큰 값을 먼저 줄여 값들을 최대한 고르게 만든다.
- 매 순간 가장 큰 작업을 줄이는 **그리디 알고리즘**을 사용한다.
- 가장 큰 값을 반복해서 찾아야 하므로 **최대 힙**이 적합하다.
- Java의 `PriorityQueue`는 기본이 최소 힙이므로 `Collections.reverseOrder()`가 필요하다.
- 제곱의 합은 커질 수 있으므로 결과 계산에는 `long`을 사용한다.

### 한 줄 요약

> 최대 힙에서 가장 큰 작업량을 꺼내 1씩 줄이는 과정을 `n`번 반복한 뒤, 남은 작업량의 제곱을 모두 더한다.
